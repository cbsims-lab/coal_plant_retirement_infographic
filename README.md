This repository contains the R code, YAML script, and raw data needed to create the interactive coal plant retirement infographic.

To generate the map under the existing YAML workflow script, manually trigger the workflow. To do this, first click on the Actions tab at the top of the repository's homepage. Then click "Run Map Generation" on the left-hand side of the Actions page. Then click the gray "Run workflow" button towards the right-hand side of the Actions page; a dropdown menu will appear and present a green "Run workflow" button, which you must then click. Doing so triggers the workflow, which takes 2-3 minutes to run. After the workflow concludes, give GitHub 1-2 minutes to deploy the new URL before accessing it according to the instructions in the next paragraph.

To access the map's HTML URL, click on github-pages under the Deployments section on the right-hand sidebar of the repository's homepage. Doing so will take you to a deployments page where the URL can be found near the top of the page. It will look something like "https://USER.github.io/coal_plant_retirement_infographic/". It may take a few minutes after triggering the workflow for GitHub to deploy the newest URL. The URL can also be found below the "About" section on the right-hand side of the homepage, but this URL may take longer to update than the one found in the deployments page.
